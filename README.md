# Realms of Concis resourcepack

Playable client textures, menu assets and sounds for the Realms of Concis Minecraft server (26.3).

This public repository contains the resourcepack only. Plugin source, private server configuration, player data, source artwork and generation prompts are not included.

The server provides the exact download automatically. Manual installation: copy the ZIP from packs into Minecraft resourcepacks and enable it. Required third-party icon license notices are included inside the pack under licenses/.
